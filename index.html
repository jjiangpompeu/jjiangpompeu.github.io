Benvinguts als Projectes

Soc JingJing de 4rt ESO de l'Institut Pompeu Fabra.

El primer que farem es crear un compte amb el editor de p5js utilitzant el compte de l'institut

Crearem un objecte, com per exemple una cara, en l'editor anterior i es guardarà automaticament i el trobare sota el meu nom en "my sketches"

Si a l'arxiu es diu "cara 1" crearé una carpeta anomenada cara1 i dintre copiaré 3 arxius que estan a l'editor de p5,que s'anomena index.html, styles.css i sketch.js i tindré la car a la meva web /car1

Al projecte li direm "projecte cares" i al projecte 1.1 li direm "cara1"

Aquesta és una web amb menú desplegable, icones Font Awesome, mode clar i fosc, i disseny responsiu per mòbil i ordinador utilitzant Bootstrap 5.3.8. Aquest és el punt de partida per editar tot i fer projectes de digitalització artística.
